Overview

SYSTRAN is a long-established machine translation vendor, now part of ChapsVision. Its current products are neural machine translation tools for professionals and organizations that need control over where their data is processed.

The range runs from SYSTRAN translate PRO, an online tool for individual professionals, to SYSTRAN translate Enterprise for teams, a dedicated Private Cloud, and SYSTRAN translate Server installed on the customer’s own infrastructure. SYSTRAN Model Studio lets organizations customize and train translation models, and a translate API serves developers.

Features include file translation in 30+ document formats, PDF translation, Neural Fuzzy Adaptation using translation memories, a browser extension, a Microsoft Office add-in and a Speech Add-on. SYSTRAN states ISO 27001 certification and GDPR-compliant hosting.

Pros & Cons

Advantages

  • On-premise and private cloud options for sensitive data
  • Published prices for Translate PRO and the API
  • 14-day free trial
  • Model customization with Model Studio
  • Office add-in, browser extension and desktop apps

Disadvantages

  • Prices are listed in euros
  • Translation memories, glossaries and CAT/TMS connectors require Translate PRO Premium
  • Translate PRO is limited to 10 users and 25 MB files
  • Enterprise, Private Cloud and Server prices are not published

Pricing

SYSTRAN lists these prices:

Translate PRO Plus (€17.99/user/month annual, €24.99 monthly)

About 1,000,000 characters (about 600 pages) per user per month, file and PDF translation, dictionaries, Office add-in, up to 10 users.

Translate PRO Premium (€34.99/user/month annual, €49.99 monthly)

About 3,000,000 characters (about 2,000 pages) per user per month, plus CAT/TMS connectors, translation memories, normalization dictionaries, post-editing and formal/informal tone.

Translate PRO API (€14.99/month)

1 million characters per month; a 14-day free trial includes 500,000 characters.

SYSTRAN translate Enterprise (pay per use), Private Cloud and Translate Server (unlimited volume) are quote-based.

Frequently Asked Questions

Who owns SYSTRAN?

ChapsVision, a French data-processing group, acquired SYSTRAN in January 2024. The products are sold as SYSTRAN by ChapsVision.

How much does SYSTRAN cost?

Translate PRO Plus is €17.99 per user per month billed annually (€24.99 monthly) and Premium is €34.99 (€49.99 monthly). The API starts at €14.99 per month.

Can SYSTRAN run on-premise?

Yes. SYSTRAN translate Server is deployed on the customer’s own infrastructure; a dedicated Private Cloud is also available.

Is there a free trial?

Yes, a 14-day free trial. The API trial includes 500,000 characters.

How many languages are supported?

SYSTRAN’s Translate PRO pricing lists 55 languages.
