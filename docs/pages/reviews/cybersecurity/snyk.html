Overview

Snyk is a developer security platform. Its core products scan first-party code (Snyk Code, SAST), open source dependencies (Snyk Open Source, SCA), container images (Snyk Container) and infrastructure as code (Snyk IaC). It also offers Snyk API & Web for dynamic testing and Snyk Secrets. Results are delivered in the IDE, the CLI, source code managers and pipelines.

Snyk now presents itself as an AI Security Platform. DeepCode AI powers its code analysis and Snyk Agent Fix generates fixes. The Evo line, which includes Evo Agent Security, Evo AI-SPM and Continuous Offensive Security, targets AI-generated code and AI agents, and Snyk says it governs coding tools such as Claude, Cursor, Copilot, Codex and Windsurf. Evo capabilities require an Enterprise subscription.

Snyk publishes its prices: a Free plan, a Team plan starting at $25 per month for teams of up to 10 developers, and Enterprise contracts paid with prepaid credits at $1 per credit.

Key Features

Snyk Code (SAST)

Scans first-party code; 100 tests per month on Free, 1,000 on Team.

Snyk Open Source (SCA)

Finds vulnerable open source dependencies.

Snyk Container

Scans container images for vulnerabilities.

Snyk IaC

Checks infrastructure-as-code files for security misconfigurations.

Snyk Agent Fix

AI-generated fixes for issues found in code.

Developer Integrations

IDE, CLI and source code manager integrations on every plan; Jira from Team.

Pros & Cons

Advantages

  • Free plan includes Snyk Code, Open Source, IaC and Container
  • Published Team price, billed monthly
  • Works where developers work: IDE, CLI, repositories
  • Enterprise access is not cut off when prepaid credits run out; overage is billed in arrears
  • Open source maintainers can apply for free access

Disadvantages

  • Free plan is limited to 5 projects and 100 Snyk Code tests per month
  • Team plan is capped at 10 developers and 100 projects
  • Evo and other new AI security capabilities require Enterprise
  • Credit-based Enterprise pricing requires forecasting usage per contributor and per image

Pricing

Plans as published on Snyk’s pricing page:

Free ($0/month)

5 projects, 100 Snyk Code tests per month, Snyk Open Source, Code, IaC and Container, IDE, CLI and SCM integrations.

Team (from $25/month, billed monthly)

For teams of up to 10 developers: 100 projects, 1,000 Snyk Code tests per month, Jira integration and next-business-day support.

Enterprise (contact sales)

Prepaid credits at $1 per credit, valid for the contract term, usable on any Snyk Platform capability.

Enterprise examples published by Snyk: Code and Open Source use 1.0 credit per active contributor per day; Container uses 0.33 credits per monitored image per day.

Best Use Cases

Best For:

  • Development teams that want security checks in the IDE, CLI and pull requests
  • Small teams that can work within the Free or Team limits
  • Organizations securing code written with AI coding assistants (Enterprise)
  • Open source maintainers (free access by application)

May Not Be Ideal For:

  • Teams that need runtime vulnerability scanning of servers and networks
  • Teams larger than 10 developers that want to stay on a self-service plan

Frequently Asked Questions

Is Snyk free?

Yes. The Free plan costs $0 and includes 5 projects and 100 Snyk Code tests per month, along with Open Source, IaC and Container scanning.

How much is the Team plan?

It starts at $25 per month, billed monthly, for teams of up to 10 developers.

How does Enterprise pricing work?

Enterprise customers buy prepaid credits at $1 per credit. Each capability consumes credits at a published rate, for example 1.0 credit per active contributor per day for Code and Open Source.

What is Snyk Evo?

Snyk’s line of AI security capabilities, including Evo Agent Security, Evo AI-SPM and Continuous Offensive Security. It requires an Enterprise subscription.

Does Snyk work with AI coding assistants?

Snyk says its platform governs AI coding tools such as Claude, Cursor, Copilot, Codex and Windsurf.
