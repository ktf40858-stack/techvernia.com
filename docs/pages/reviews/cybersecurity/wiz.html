Update — October 2026: Google completed its $32 billion acquisition of Wiz on March 11, 2026. Wiz announced the closing the same day and says it remains a multi-cloud platform for customers on AWS, Azure, GCP and OCI.

Overview

Wiz is a cloud security platform that became part of Google in March 2026. Wiz says it remains a multi-cloud platform, with customers across AWS, Azure, Google Cloud and Oracle Cloud Infrastructure.

The platform has three product lines. Wiz Code secures development from the IDE to CI/CD; Wiz Cloud covers cloud and AI risk across infrastructure and data; Wiz Defend provides runtime protection and threat detection, using the Wiz Sensor (an eBPF runtime sensor) to detect and block exploitation attempts. All three share the Wiz Security Graph, which analyzes the relationships between resources to connect code, cloud and runtime context.

Wiz connects to cloud accounts through APIs for agentless visibility, then adds attack path analysis, cloud threat intelligence and code-to-cloud correlation that links running resources back to the code, pipeline and developer that created them. Wiz sells packages named Wiz One and Wiz Go plus à la carte options; prices are only available through a custom quote.

Key Features

Agentless Visibility

Connects via cloud APIs to cover cloud and AI resources without installing agents.

Security Graph

Maps relationships between resources, identities, data and code to show real attack paths.

Wiz Code

Scans code from the IDE through CI/CD and traces cloud risks back to their source.

Wiz Cloud

Finds misconfigurations, vulnerabilities and AI risks across cloud infrastructure and data.

Wiz Defend

Runtime threat detection and response, with the eBPF-based Wiz Sensor for blocking.

Attack Path Analysis

Prioritizes combinations of issues that create an exploitable path.

Pros & Cons

Advantages

  • Agentless onboarding through cloud APIs
  • One graph shared by code, cloud and runtime products
  • Supports AWS, Azure, Google Cloud and OCI
  • Code-to-cloud tracing back to the responsible pipeline and developer

Disadvantages

  • No public pricing; custom quote only
  • Runtime blocking requires deploying the Wiz Sensor
  • No free trial listed on the pricing page
  • Ownership change: now part of Google (March 2026)

Best Use Cases

Best For:

  • Cloud-first companies running workloads on several cloud providers
  • Security teams that need fast visibility without deploying agents
  • AppSec and cloud teams that want to trace issues back to code and owners
  • Organizations securing AI applications and models in the cloud

May Not Be Ideal For:

  • Mostly on-premises data centers
  • Small teams that need published, self-service pricing
  • Buyers who want runtime protection without deploying a sensor
