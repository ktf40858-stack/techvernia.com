Overview

Qualys VMDR (Vulnerability Management, Detection and Response) is the core vulnerability management application of Qualys’s cloud platform, which Qualys now calls the Enterprise TruRisk Platform. It discovers and inventories known and unknown assets across hybrid environments, detects vulnerabilities and prioritizes them with TruRisk scoring and the Qualys Detection Score (QDS).

Data comes from Qualys sensors: virtual scanners, virtual passive scanning sensors and Cloud Agents, which Qualys includes with VMDR. VMDR correlates vulnerabilities with the patches that fix them, including the latest superseding patch, and can hand off to Qualys Patch Management for automated and zero-touch patching.

Qualys sells VMDR per asset, with nothing to install on the platform side, and offers a 30-day free trial. Patch Management, ServiceNow CMDB synchronization and some other capabilities are add-ons.

Key Features

Asset Discovery

Detects and inventories known and unknown assets connecting to a hybrid IT environment.

TruRisk Prioritization

Quantifies risk across vulnerabilities, assets and asset groups using factors beyond the CVSS score.

Qualys Detection Score

QDS ranks individual detections and shows the risk factors behind critical scores.

Patch Detection

Maps vulnerabilities to the patches that fix them, including the latest superseding patch.

Patch Management (add-on)

Deploys patches through Qualys Cloud Agents, including zero-touch patching.

Included Sensors

Unlimited virtual scanners, virtual passive scanning sensors and Cloud Agents.

Frequently Asked Questions

What does VMDR stand for?

Vulnerability Management, Detection and Response.

How is Qualys VMDR priced?

Per asset, on quote. Qualys does not publish list prices.

Is there a free trial?

Yes. Qualys offers VMDR at no cost for 30 days.

Does VMDR patch systems?

VMDR detects missing patches and maps them to vulnerabilities. Deploying patches uses Qualys Patch Management, an add-on that runs through the Cloud Agents.

What is TruRisk?

Qualys’s risk scoring, which quantifies risk across vulnerabilities, assets and asset groups using factors beyond the CVSS score.
