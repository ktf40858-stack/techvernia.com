Overview

Lacework was a cloud security company known for behavior-based anomaly detection in cloud environments. Fortinet acquired it in August 2024 and now sells the platform as FortiCNAPP, which Fortinet describes as “built natively for the cloud from Lacework technology and integrated into the Fortinet Security Fabric”.

FortiCNAPP combines cloud security posture management (CSPM), Kubernetes posture (KSPM), cloud identity entitlement management (CIEM) and workload protection (CWPP). It also covers infrastructure-as-code scanning, vulnerability management in the context of your environment, code security (SAST, SCA and SBOM), Kubernetes security and cloud detection and response. Workloads are monitored continuously for unusual behavior without writing rules.

The platform assesses posture across AWS, Azure and Google Cloud. Fortinet does not publish prices; its page offers a product demo, contact with sales and a FortiCNAPP ordering guide.

Key Features

CSPM and Compliance

Visibility of cloud resources, misconfiguration risk and continuous compliance.

CIEM

Continuous visibility of cloud identities toward least-privilege access.

Anomaly Detection

Monitors workloads for unusual behavior without rule writing.

Vulnerability Management

Prioritizes vulnerabilities by context; Fortinet claims up to 90% less noise.

Code Security

IaC scanning, SAST, SCA and SBOM to catch issues before deployment.

Kubernetes and CDR

Kubernetes security and cloud detection and response.

Pros & Cons

Advantages

  • Posture, identity, workload and code security in one platform
  • Behavior-based detection inherited from Lacework
  • Covers AWS, Azure and Google Cloud
  • Integrates with the Fortinet Security Fabric, FortiSOAR and FortiGuard
  • Contextual vulnerability prioritization

Disadvantages

  • No published pricing
  • Rebranding means older Lacework documentation and names may be outdated
  • Strongest fit for organizations already using Fortinet products
  • The product page does not say whether deployment is agent-based or agentless

Pricing

Pricing is quote-based. Fortinet does not publish FortiCNAPP prices.

The cloud accounts, workloads and capabilities (posture, identity, workload, code) to cover.

Best Use Cases

Best For:

  • Multi-cloud teams: posture and threat detection across AWS, Azure and Google Cloud
  • Fortinet customers: organizations extending the Security Fabric to cloud workloads
  • DevSecOps: IaC, SAST and SCA alongside runtime security
  • Kubernetes users: KSPM and container workload protection

May Not Be Ideal For:

  • Buyers who need public pricing
  • Teams looking for a standalone firewall or on-premises tool
