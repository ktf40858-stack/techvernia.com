Overview

Tenable.io is a cloud-based vulnerability management platform from the makers of Nessus, the world's most widely deployed vulnerability scanner. It provides comprehensive visibility into vulnerabilities across IT, cloud, and OT environments.

The Vulnerability Priority Rating (VPR) uses machine learning to analyze threat intelligence, exploit availability, and real-world attack data to prioritize vulnerabilities that pose actual risk—not just high CVSS scores.

Tenable.io's asset-centric approach provides continuous visibility into the attack surface, helping organizations understand what's exposed and where to focus remediation efforts.
