Overview

Gradescope is a grading platform owned by Turnitin. Instructors use it for exams, homework, programming projects and bubble sheets, whether online or in class. Students upload scanned PDFs or photos, and code can be submitted from GitHub or Bitbucket.

Grading happens question by question with a flexible rubric. Rubric changes apply to work that was already graded, which keeps feedback consistent across a large class. On the Institutional license, Gradescope AI can group similar answers so instructors grade each group once.

There are two plans: a free Basic plan and an Institutional license with quote-based pricing. Institutions can trial the full feature set for one term.

Key Features

Dynamic Rubrics

Apply feedback with one click; rubric edits apply to submissions already graded.

Question-by-Question Grading

Grade one question across all students before moving to the next.

AI-Assisted Grading

Gradescope AI forms groups of similar answers for some question types (Institutional).

Programming Assignments

Autograders give students immediate feedback, plus manual grading and code similarity checks (Institutional).

Bubble Sheets and Online Assignments

Additional assignment types available on the Institutional license.

Statistics and Export

Per-question and per-rubric statistics, regrade requests and grade export.

Pros & Cons

Advantages

  • Free Basic plan with dynamic rubrics and statistics
  • Consistent feedback thanks to retroactive rubric changes
  • Handles paper exams, homework and code
  • Students can submit with a mobile app
  • One-term Institutional trial with the full feature set

Disadvantages

  • AI grading, programming assignments, bubble sheets and LMS integration require the Institutional license
  • Institutional pricing is quote-based
  • LMS integration and SSO are not included in the Institutional trial
  • Built for instructors, not as a study tool for students

Pricing

Gradescope offers a free Basic plan and a quote-based Institutional license.

Basic (Free)

Dynamic rubrics, question-by-question grading, PDF assignments, statistics, regrade requests, data export and the student mobile app.

Institutional (Quote)

Adds AI-assisted grading, collaborative and anonymous grading, programming, online and bubble sheet assignments, code similarity, LMS integration, SSO and an admin dashboard.

Institutional Trial

One term with the full feature set, except LMS integration, SSO, the admin dashboard, course duplication and dedicated onboarding.

After the trial ends, you can keep using the Basic plan for free.

Best Use Cases

Gradescope Excels For:

  • Large university courses with paper-based exams
  • Computer science courses that need autograded programming assignments
  • Departments that want consistent grading across several TAs

May Not Be Ideal For:

  • Students looking for a tutoring or study tool
  • Teams that need LMS integration but cannot buy an Institutional license
  • Very small classes where manual grading is quick

Comparison

Gradescope is a grading tool for instructors; most other tools in this category, such as Cognii or ALEKS, give feedback to students while they learn. See other tools in our AI education category.

Frequently Asked Questions

Is Gradescope free?

Yes, the Basic plan is free. It includes dynamic rubrics, question-by-question grading, PDF assignments, statistics, regrade requests and data export.

What does the Institutional license add?

AI-assisted grading, collaborative and anonymous grading, programming, online and bubble sheet assignments, code similarity, LMS integration, SSO and an administrator dashboard.

Does Gradescope use AI?

Yes. On the Institutional license, Gradescope AI groups similar answers for some question types and helps with roster matching.

Can Gradescope grade code?

Yes. Programming assignments with autograders are part of the Institutional license, and code can be submitted from GitHub or Bitbucket.

Is there a free trial?

Yes. The Institutional trial lasts one term and includes the full feature set except LMS integration, SSO, the admin dashboard, course duplication and dedicated onboarding.

Who owns Gradescope?

Turnitin, LLC.
