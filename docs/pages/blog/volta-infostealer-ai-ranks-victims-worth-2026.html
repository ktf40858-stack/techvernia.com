VOLTA: The Infostealer That Asks AI What You Are Worth

On October 31, Cisco Talos described VOLTA, a Windows infostealer that does not stop at stealing passwords and sessions. It sends a profile of each victim to a large language model and asks it to rank the victim's assets and judge their security habits. If one model refuses, it simply asks the next. Here is how it works, what it really changes, and what defenders can do today.

A Thief With an Analyst

Infostealers are the most common malware on Windows today. They grab saved passwords, cookies and crypto wallets, then ship everything to an operator who decides what is worth using. That last step, deciding who is worth the effort, has always been human work.

VOLTA, also called VOLTA-AUTODOXER, hands that step to an AI. Cisco Talos first saw it on October 11, 2026 and published its analysis on October 31. It is sold as a builder, so each buyer gets a custom Windows binary (PE32+, x86-64) that deletes itself once the job is done.

What VOLTA Steals

  • Browsers: saved passwords, cookies and payment cards.
  • Apps: Outlook, Slack, Discord, Telegram, Steam and Roblox data.
  • Technical secrets: SSH keys, cloud and VPN configuration files, crypto wallets and saved Wi-Fi passwords.

Then it goes a step further than a classic stealer. Using the sessions it just stole, VOLTA searches Gmail for retail receipts and pulls Uber Eats and DoorDash order history to confirm the victim's home address. Stolen data becomes a physical location.

The AI Stage, Step by Step

  1. Everything collected goes into a file called Identity_Report.txt.
  2. VOLTA converts it to JSON and sends it, with a system prompt, to the OpenRouter chat completions API at temperature 0.2.
  3. The default model is Claude Opus 4.6.
  4. VOLTA scans the reply for refusal phrases such as "I can't" or "I'm not able". If it finds one, it sends the same request to Kimi K2, then to Gemini 2.5 Flash.
  5. The answer is saved as AI_Analysis.txt, and both files can be packed into volta_dox.zip for the operator.

The report has two sections. "WHAT THEY'RE WORTH" ranks the victim's assets as low, medium or high value. "THEIR OPSEC" judges their password habits. The data sent to the model includes the victim's home address, employer, inferred birth year, last four card digits and Slack workspaces.

Key Point

Refusals Are Not a Security Control

The safety training of one model does work in the narrow sense: a refusal is a real outcome VOLTA had to plan for. But the attacker does not need every model to say yes. They need one. A simple string check and a list of fallbacks turns each refusal into a short delay. Model-level guardrails reduce misuse; they cannot be the only line of defense when attackers can shop across providers through a single API router.

What Really Changes: "Effort Displacement"

Talos calls this effort displacement. A stealer campaign can collect thousands of logs. Sorting them, finding the crypto holder, the company admin or the person with a saved corporate VPN profile, used to take time and skill. VOLTA turns that triage into one API call per victim.

Three details make this worth attention:

  • The AI step is optional. Without an API key, VOLTA still steals and sends everything. The model does not make the theft possible; it decides who gets hit first.
  • No attacker server to block. VOLTA relies only on third-party services. There is no classic command-and-control domain to add to a blocklist.
  • Doxing at scale. Receipts and delivery history turn a stolen login into a home address. That raises the risk well beyond account takeover, toward extortion and physical threats.

How to Detect and Defend

Chrome launched with --headlessVOLTA uses headless Chrome to get around App-Bound Encryption. Use application control to limit which processes can do this, and at minimum alert when anything outside known developer tools does.

If You Are Infected

Response Checklist

  • Isolate the device and keep alerts and logs before cleaning.
  • Keep %APPDATA%\volta_debug.txt. The malware deletes itself, but this log can show what was collected and whether the AI call worked.
  • Reset passwords from a clean device, never from the infected one, starting with primary email and accounts that can reset others.
  • Revoke sessions and tokens, including Slack, cloud and VPN access, and rotate SSH keys.
  • Move crypto to a new wallet created on a clean, ideally air-gapped device if a seed phrase was stored in plain text.
  • Involve your security team if any work credentials were on the machine.

The Fine Print

One sample, early days. Talos analyzed a single sample. There is no published victim count, no known universal delivery lure, and no reported financial losses yet.

We also do not know how many buyers have the builder, or how often the AI stage is actually configured in real campaigns. The behavior is documented; the scale is not.

VOLTA is a Windows infostealer documented by Cisco Talos on October 31, 2026 that sends each victim's stolen profile to an AI model through OpenRouter, starting with Claude Opus 4.6 and falling back to Kimi K2 and Gemini 2.5 Flash after a refusal, to rank the victim's value and security habits. The AI stage is optional, but it turns the operator's triage into one API call. Defenders should watch headless Chrome launches and unexpected LLM API traffic.

Frequently Asked Questions

What is VOLTA?
VOLTA, also called VOLTA-AUTODOXER, is a Windows infostealer sold as a builder. Cisco Talos first saw it on October 11, 2026. It steals browser data, app sessions, SSH keys, cloud and VPN configs and crypto wallets, then optionally asks an AI model to rank each victim's value.
Which AI models does VOLTA use?
According to Talos, its default is Claude Opus 4.6 through OpenRouter. If the reply contains a refusal phrase, it retries with Kimi K2 and then Gemini 2.5 Flash.
Does the AI make the theft possible?
No. The AI stage is optional. Without an API key, VOLTA still steals and exfiltrates data. The model only ranks victims, so the operator knows who to exploit first.
How can I detect VOLTA?
Watch for Chrome started with --headless by unexpected processes, calls to OpenRouter or other LLM APIs from machines that never use them, and files such as Identity_Report.txt, AI_Analysis.txt or %APPDATA%\volta_debug.txt.
How many people are affected?
Unknown. Talos described one sample and did not publish a victim count, a common delivery method or financial losses.

My Take

For two years, the debate was whether AI would write better malware. VOLTA shows a quieter shift: AI as the criminal's business analyst. It reads your receipts, your Slack workspaces and your password habits, then writes a short report on your value.

As a network security engineer, I see a clear lesson in where to look. The theft itself happens on the endpoint, but the AI stage needs to leave the network. Egress is where this kind of malware shows itself. A workstation sending personal data to an LLM router at 3 a.m. is now a detection rule worth writing, and most SOCs do not have it yet.

The second lesson is for AI providers and API routers. Refusals clearly happen, which is why VOLTA needs a fallback list. The next step is shared abuse signals across providers, so that a request refused by one model is not quietly answered by another.
