Anomaly Detection

Resumen

Lacework is a data-driven cloud security platform that uses machine learning to automatically learn what's normal in your cloud environment and detect anomalies that could indicate threats, misconfigurations, or compliance violations.

The platform's Polygraph technology builds a behavioral baseline across your entire cloud infrastructure—including workloads, containers, Kubernetes, and cloud accounts—to identify suspicious activities without requiring custom rules or signatures.

Now part of Fortinet following a 2026 acquisition, Lacework continues to provide comprehensive cloud workload protection (CWPP), cloud security posture management (CSPM), and infrastructure as code security capabilities.
