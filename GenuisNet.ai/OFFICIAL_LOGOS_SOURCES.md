## 📝 INSTRUCTIONS

### Step 1: Download Logos
1. Visit each tool's official source or Brandfetch page
2. Download the logo in **SVG format** (preferred) or high-res PNG
3. For Brandfetch: Click on the logo → Download → Select SVG

### Step 2: Rename Files
Rename downloaded files to match the exact naming convention:
- Format: `[tool-slug].svg`
- Example: `chatgpt.svg`, `copy-ai.svg`, `github-copilot.svg`
- Use lowercase with hyphens (not spaces)

### Step 3: Save to Correct Folder
Save each logo to its category folder:
```
assets/images/tools/

├── writing/
├── image/
├── video/
├── audio/
├── coding/
├── productivity/
├── seo/

```

```bash

```
