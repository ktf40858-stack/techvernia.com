## 📏 Spécifications des Logos

### Format
- **Type**: PNG avec fond transparent OU SVG
- **Taille**: 120x120px minimum (pour PNG)
- **Qualité**: Haute résolution
- **Fond**: Transparent de préférence

### Emplacement
Sauvegarder les logos dans:
```
assets/images/tools/[category]/[tool-name].png
```

Exemples:
- `assets/images/tools/chatbots/chatgpt.png`
- `assets/images/tools/audio/elevenlabs.png`
- `assets/images/tools/medical/viz-ai.png`

## 🔧 Méthode 2 : Utiliser un Service d'API

### Clearbit Logo API (Gratuit)
```
https://logo.clearbit.com/[domain].com
```

Exemples:
- ChatGPT: `https://logo.clearbit.com/openai.com`
- Claude: `https://logo.clearbit.com/anthropic.com`
- Notion: `https://logo.clearbit.com/notion.so`

### Google Favicon
```
https://www.google.com/s2/favicons?domain=[domain].com&sz=128
```

## 🛠️ Méthode 3 : Script Automatique (Partiel)

Utiliser le script Python fourni pour télécharger automatiquement certains logos:

1. Placer tous les logos dans leurs répertoires respectifs

4. Vérifier que tous les logos s'affichent correctement

## 💡 Astuce Rapide

Pour télécharger rapidement un logo:
1. Ouvrir le site officiel de l'outil
2. Clic droit sur le logo → "Enregistrer l'image sous"
3. Renommer selon la convention: `[tool-name].png`
4. Redimensionner si nécessaire (120x120px)
5. Placer dans le bon répertoire
