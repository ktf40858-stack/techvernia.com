## 🛠️ Maintenance et Mises à Jour

### Pour Ajouter une Nouvelle Page:

1. Créer la page HTML en anglais
2. Exécuter l'extraction:
   ```bash
   python3 batch_translator_all_categories.py
   ```
3. Générer les traductions:
   ```bash
   python3 translate_all_complete.py
   ```
4. Appliquer data-i18n:
   ```bash
   python3 apply_i18n_all_pages.py
   ```
5. Injecter dans i18n.js:
   ```bash
   python3 inject_all_translations_final.py
   ```

### Pour Modifier une Traduction:

**Option 1: Modifier le JSON**
1. Ouvrir `all_full_translations_[langue].json`
2. Trouver la clé à modifier
3. Changer la traduction
4. Ré-exécuter `inject_all_translations_final.py`

**Option 2: Modifier directement i18n.js**
1. Ouvrir `GenuisNet.ai/js/i18n.js`
2. Chercher la clé (ex: `review.chatgpt.title`)
3. Modifier la valeur
4. Sauvegarder
